# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **Svelte Edge CMS** very seriously. If you discover a security vulnerability, please do NOT create a public issue on GitHub.

Instead, please report it via **[GitHub Private Vulnerability Reporting](https://github.com/stevedat/svelte-edge-cms/security/advisories/new)**.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please provide:
1. A clear description of the vulnerability and its potential impact.
2. Step-by-step instructions to reproduce the issue (proof-of-concept code or HTTP requests).
3. The affected component, route, or environment (e.g., Cloudflare Workers, Vercel Edge).
4. Any potential mitigations or suggested fixes.

### Response Timeline

- **Initial Triage:** Within 48 hours of receipt.
- **Status Update:** Regular updates as we investigate and develop a patch.
- **Public Disclosure:** Coordinated after a fix has been released and verified.

Thank you for helping keep Svelte Edge CMS and its community safe!
